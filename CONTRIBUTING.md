# Contributing to Quiver

Contributions are very welcome! Whether you're fixing a bug, improving the query language, adding tests, or proposing a new feature, your help is appreciated.

1. Fork the repository.
2. Clone your fork.
3. Create a branch for your changes.
4. Make your changes and add tests where appropriate.
5. Run the test suite locally: `gradle test`
6. Open a pull request against `main`.

## Pull Requests

- Keep changes focused and explain their purpose.
- Include tests for new functionality and bug fixes.
- Make sure all existing tests pass.
- Update documentation when necessary.

## Reporting Issues

Found a bug or have an idea? Open an issue with enough detail to reproduce the problem or explain the proposed improvement.

---
Don't hesitate to ask questions or propose ideas before implementing something substantial.

Thanks for contributing!
